# local-chatbot

A web-based chatbot interface built with separate HTML and CSS files, designed for laptop and responsive viewports with API integration.

## Features

- **Separate HTML & CSS Structure:** Clean separation between markup (`index.html`) and styling (`style.css`)[cite: 1, 2].
- **Laptop & Responsive Layout:** Built to fit laptop screens comfortably with a fixed bottom input bar and media queries for smaller screens[cite: 1, 2].
- **Initial Greeting State:** Starts with a default welcome message (`"Hello! 👋 How can I help you today?"`).
- **API & Postman Ready:** Tested with Gemini API endpoints and cURL requests via Postman before wiring up live chat responses[cite: 5, 6, 8].
